# 中行外币汇率监控

一个基于 Electron 的 Windows 桌面悬浮汇率监控工具。数据优先使用中国银行外汇牌价，支持监控人民币汇率，也支持通过人民币牌价换算两种外币之间的交叉汇率。

## 功能

- 桌面悬浮窗，置顶显示汇率
- 支持多个监控浮窗
- 支持选择基准货币和报价货币，例如 `GBP/EUR`
- 支持拖拽、无间距窗口磁吸和屏幕边界保护
- 支持历史汇率线图，时间范围从 30 分钟到 3 年
- 显示四位小数目标价及目标距离，悬停查看绝对差值；有效新报价达标时高亮目标行与边框
- 图表纵轴包含目标虚线；与当前报价来源不同时，虚线仅作参考对照
- 悬停查看线图范围与区间高低值；按真实时间绘图，缺失记录和数据源切换处断开
- 支持自定义涨跌提醒阈值和通知冷却时间
- 支持达到或高于、达到或低于目标汇率的提醒
- 支持调整面板白度和模糊程度，记住上次使用的货币对与外观
- 悬停查看报价来源与更新时间；涨跌幅对应所选区间首尾报价，红涨绿跌、显示为零时用灰色，通知仍比较相邻两次同来源报价

## 技术栈

Electron / JavaScript / HTML / CSS / Node.js / Cheerio

## 安装

需要 Node.js 20.18.1 或更高版本，在项目目录安装依赖。

```bash
npm install
```

## 运行

双击运行，不显示命令行窗口：

```text
Run.vbs
```

或手动执行：

```bash
npm start
```

## 使用

- 左键拖动：移动悬浮窗
- 右键点击：打开菜单
- 选择基准货币：你手里的货币
- 选择报价货币：你想换成的货币
- 线图范围：选择短时记录或长期历史日线
- 涨跌提醒：关闭或选择 0.1%、0.3%、0.5%、1%，也可自定义；默认 0.5%，比较相邻两次成功获取的汇率
- 提醒冷却时间：可选 1、5、15、30、60 分钟或自定义正数分钟（支持小数），默认 5 分钟；涨跌和目标提醒分别计时
- 目标汇率提醒：选择达到或高于、达到或低于目标价，也可关闭；持续达标期间不重复提醒
- 提醒设置：按货币对保存，下次启动自动恢复
- 面板设置：调整白度和模糊程度
- 新增监控浮窗：创建另一个独立汇率窗口
- 关闭当前浮窗：关闭当前窗口，全部关闭后程序退出

例如想看“1 英镑能换多少欧元”：

```text
基准货币：英镑
报价货币：欧元
显示结果：GBP/EUR
```

数值变大，表示 1 英镑能换到更多欧元。

## 数据说明

中国银行页面提供的是各外币兑人民币牌价。非人民币货币对通过交叉计算得到：

```text
GBP/EUR = GBP/CNY ÷ EUR/CNY
```

当前使用的是中国银行公开外汇牌价中的现汇卖出价，仅供个人参考，不构成投资或交易建议。

中行数据获取失败时，最新汇率和提醒会回退使用 Frankfurter 参考汇率。不同来源的报价口径不同，切换来源时重新建立涨跌比较基准，不把来源价差作为涨跌提醒；目标价仍按当前来源判断。实际兑换以银行或交易平台报价为准。

## 历史线图

- `30min`、`1h`、`2h`：使用程序运行期间保存的本地记录，关闭期间不补录。
- `1d`、`2d`、`1周`、`1个月`、`3个月`、`6个月`、`1年`、`2年`、`3年`：从 Frankfurter 查询历史日线，无需程序持续运行。

长期日线为外部参考汇率，不是中国银行现汇卖出价，也不代表分钟级走势。启动时先显示本地缓存价格，再刷新最新汇率。

线图纵轴自动缩放；短时记录相隔超过 2 分钟、日线相隔超过 1.5 天时断开，日线空白可能来自周末或假日无报价。

中行报价超过 30 分钟、参考日线超过 4 天提示“数据未更新”；超过 2 分钟未成功获取提示“获取已延迟”。这些状态不代表休市，悬停可查看具体说明。

旧报价、缓存和获取异常时，价格常驻灰显；更新恢复后恢复正常颜色。图表悬停详情列出曲线末点和面板报价，两者可能来自不同日期或数据源；历史穿越目标价不会补发通知。

## 开发检查

执行 `npm test` 运行逻辑测试，执行 `npm run check` 检查 JavaScript 语法。系统通知需允许 Windows 通知，实际弹窗可能受勿扰设置影响。

当前入口为 `electron/main.js`；`floating_monitor.py` 和 `floating_monitor_qt.py` 为保留的旧版实现，不由 `Run.vbs` 或 `npm start` 启动，旧版 Python 依赖不包含在 npm 安装中。
