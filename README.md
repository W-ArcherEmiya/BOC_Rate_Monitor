# 💱 中行外币汇率监控(Exchange Monitor Float)

一个轻量级、无边框、半透明的桌面级外汇实时监控工具。基于 Python 和 Tkinter 开发，数据直连中国银行官方外汇牌价。专为需要长时间盯盘外汇波动（如留学生换汇、海淘、跨境交易）的用户设计。

## ✨ 核心特性

* **🖥️ 极客 UI 体验**：无边框设计，85% 半透明沉浸式悬浮，强制置顶（Always on Top），工作学习时不遮挡视线。
* **🧲 多窗口磁吸对齐**：支持无限克隆监控浮窗。多个浮窗靠近时会自动触发边缘磁吸（Magnetic Snapping），可自由拼装成整齐的汇率矩阵看板。
* **🛡️ 屏幕防越界边界保护**：原生拖拽逻辑优化，浮窗永远不会被意外拖出屏幕可视范围外。
* **🌍 全能货币切换**：支持右键呼出上下文菜单（Context Menu），一键无缝切换英镑、美元、欧元、日元等多种主流货币。
* **🔔 系统级智能通知**：
* **涨跌波动提醒**：智能过滤无效的微小波动，仅在涨跌幅度达到阈值时推送系统级桌面通知。
* **目标价强提醒**：可在右键菜单中自定义“目标买入价”，一旦跌破心理价位，立即触发系统高优报警。


* **🤖 拟人化防封杀爬虫**：内置时间戳破除 CDN 缓存机制，结合 60~120 秒完全随机的休眠拉取策略，100% 模拟真实人类行为，确保本地 IP 绝对安全。

## ⚙️ 环境依赖

确保你的电脑上已安装 Python 3.x，然后在终端中运行以下命令安装所需依赖库：

```bash
pip install requests beautifulsoup4 plyer

```

## 🚀 运行与使用

双击运行根目录下的 `Run.bat` 文件，即可静默启动悬浮窗。

## 🖱️ 交互操作指南

* **移动位置**：鼠标 `左键按住` 浮窗任意位置即可自由拖拽。
* **呼出菜单**：鼠标 `右键点击` 浮窗，弹出高级控制台。
* **新增浮窗**：在右键菜单中选择 `➕ 新增一个监控浮窗`。
* **关闭程序**：在右键菜单中选择 `❌ 关闭当前浮窗`。当桌面上的所有浮窗均被关闭时，后台 Python 进程会自动彻底释放。
